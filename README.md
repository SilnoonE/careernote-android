# CareerNote · 커리어노트

Android 취업 준비·커리어 기록 앱의 공개용 소스 스냅샷과 개발 기록입니다.

## 기능과 기술

- 기업 지원 상태, 일정, 검색·필터, 면접 기록
- 자기소개서·이력서·포트폴리오·프로젝트·경력·교육·자격증 관리
- 제출 서류 스냅샷, PDF 연결, 초안 저장, 백업·복원
- Kotlin, Jetpack Compose, Room, Hilt, DataStore

기능 목록은 구현 영역을 설명하며, 모든 예외 상황에 대한 검증 완료를 의미하지 않습니다.

## 공개 범위

화면, 데이터 모델, 저장소, 마이그레이션, 백업·복원, 알림 등 앱 구조를 공개합니다.
운영 광고 구현·광고 ID, 서명 키, 비밀번호, 개인 데이터, 로컬 환경 설정 및 배포 바이너리는 제외했습니다.
공개 사본의 광고 영역은 설명용 자리표시자로 대체했습니다. 원본 앱의 광고와 하단 탭은 변경하지 않았습니다.

## 실행 환경

Android Studio, JDK 21, Android SDK 36이 필요합니다. SDK 위치는 개인 환경에서 설정하세요.
프로젝트 루트에서 `./gradlew :app:assembleDebug`를 실행할 수 있습니다(Windows: `gradlew.bat`).
공개 사본은 별도 빌드를 실행하지 않았으므로 빌드 성공을 보증하지 않습니다.
