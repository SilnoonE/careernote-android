# CareerNote · 커리어노트

Android 취업 준비·커리어 기록 앱의 공개용 소스와 개발 기록입니다.
기업 지원부터 제출 서류, 면접 준비, 복기와 연습까지 하나의 흐름으로 연결해 가고 있습니다.

## 업데이트 이력

최신 기록부터 이전 기록 순서로 나열했습니다. 아래로 스크롤하면 이전 업데이트를 계속 볼 수 있습니다. 날짜는 공개 커밋과 개발 기록을 기준으로 하며, 최초 공개 이전 과정은 회고로 구분했습니다. 앞으로도 새 업데이트는 이 목록 맨 위에 추가하고 기존 항목은 유지합니다.

## 왜 만들었나요?

취업 준비에서는 기업별 지원 현황, 제출한 서류, 면접 질문, 개인 경험이 서로 다른 곳에 흩어지기 쉽습니다. 커리어노트는 이 기록들을 한 앱에서 관리하고, 축적한 경험을 다음 지원에 다시 활용하는 흐름을 목표로 합니다.

핵심 사용 흐름은 `경험 기록 → 서류 작성 → 기업 지원 → 면접 준비 → 결과와 회고`입니다. 현재 공개 코드는 이 흐름을 구현해 가는 개발 스냅샷입니다.

## 개발 방식

AI 지원으로 구현과 코드 검토를 반복했습니다. 기능 구현 보고를 그대로 완료로 인정하지 않고 소스의 호출 경로, UI 연결, 저장 방식, 실패 시 동작을 대조했습니다. 이 저장소는 그 과정과 남은 검증을 함께 공개합니다. 모든 코드를 독립적으로 직접 작성했거나 모든 테스트를 통과했다고 주장하지 않습니다.
