# CareerNote · 커리어노트

Android 취업 준비·커리어 기록 앱의 공개용 소스 스냅샷과 개발 기록입니다.

## 기능과 기술

- 기업 지원 상태, 일정, 검색·필터, 면접 기록
- 자기소개서·이력서·포트폴리오·프로젝트·경력·교육·자격증 관리
- 제출 서류 스냅샷, PDF 연결, 초안 저장, 백업·복원
- Kotlin, Jetpack Compose, Room, Hilt, DataStore

기능 목록은 구현 영역을 설명하며, 모든 예외 상황에 대한 검증 완료를 의미하지 않습니다.

## 공개 범위

화면, 데이터 모델, 저장소, 마이그레이션, 백업·복원, 알림 등 앱 구조를 공개합니다.
운영 광고 구현·광고 ID, 서명 키, 비밀번호, 개인 데이터, 로컬 환경 설정 및 배포 바이너리는 제외했습니다.
공개 사본의 광고 영역은 설명용 자리표시자로 대체했습니다. 원본 앱의 광고와 하단 탭은 변경하지 않았습니다.

## 실행 환경

Android Studio, JDK 21, Android SDK 36이 필요합니다. SDK 위치는 개인 환경에서 설정하세요.
프로젝트 루트에서 `./gradlew :app:assembleDebug`를 실행할 수 있습니다(Windows: `gradlew.bat`).
공개 사본은 별도 빌드를 실행하지 않았으므로 빌드 성공을 보증하지 않습니다.

## 왜 만들었나요?

취업 준비에서는 기업별 지원 현황, 제출한 서류, 면접 질문, 개인 경험이 서로 다른 곳에 흩어지기 쉽습니다. 커리어노트는 이 기록들을 한 앱에서 관리하고, 축적한 경험을 다음 지원에 다시 활용하는 흐름을 목표로 합니다.

핵심 사용 흐름은 `경험 기록 → 서류 작성 → 기업 지원 → 면접 준비 → 결과와 회고`입니다. 현재 공개 코드는 이 흐름을 구현해 가는 개발 스냅샷입니다.

## 기능 지도

| 영역 | 소스에 포함된 구현 영역 | 확인할 관점 |
|---|---|---|
| 홈 | 지원 지표, 마감 일정, 커리어 팁 | 날짜 변경 시 갱신, 지표 정의 |
| 지원 관리 | 기업·직무 등록, 검색, 상태·즐겨찾기 필터, 정렬 | 저장 결과, 상태 이력, 목록과 상세 일관성 |
| 커리어 기록 | 자소서, 이력서, 포트폴리오, 프로젝트, 자격증, 면접 질문, 경력, 교육 | 편집·복제·삭제, 필수 입력 검증 |
| 제출 서류 | 서류 연결과 JSON 스냅샷, PDF 연결 | 원본 변경 후 독립 보존, 파일 생명주기 |
| 면접 | 일정과 준비 내용, 예약 알림 | 권한, 시간대, 재부팅, 클릭 후 이동 |
| 리포트 | 결과 집계와 설명 | 분모·분자, 취소 이전 이력, 표본 부족 |
| 설정 | 언어·테마, 백업·복원 | 실패 복구, 데이터 호환성 |
| AI 확장 | 제공자 인터페이스 | 외부 서비스 미연결 상태와 실제 제공 기능 구분 |

## 코드를 읽는 순서

1. `MainActivity.kt`와 `ui/screen/MainContainer.kt`: 앱 진입, 테마, 공통 화면.
2. `ui/navigation/NavGraph.kt`: 화면 이동과 인자 전달.
3. `ui/screen/ApplicationsScreen.kt`, `ApplicationDetailScreen.kt`: 지원 관리의 사용자 흐름.
4. `viewmodel/ApplicationsViewModel.kt`: 화면 상태와 사용자 동작의 데이터 연결.
5. `data/repository`, `data/database`: 저장 경계, 쿼리, 마이그레이션.
6. `viewmodel/SettingsViewModel.kt`, `util`: 백업·파일·알림과 실패 처리.

세부 설명은 [구조 안내](docs/ARCHITECTURE.md), 실제 검토 사례는 [개선 사례](docs/ENGINEERING_CASES.md), 이후 계획은 [로드맵](docs/ROADMAP.md)에 있습니다.

## 개발 방식

AI 지원으로 구현과 코드 검토를 반복했습니다. 기능 구현 보고를 그대로 완료로 인정하지 않고 소스의 호출 경로, UI 연결, 저장 방식, 실패 시 동작을 대조했습니다. 이 저장소는 그 과정과 남은 검증을 함께 공개합니다. 모든 코드를 독립적으로 직접 작성했거나 모든 테스트를 통과했다고 주장하지 않습니다.
