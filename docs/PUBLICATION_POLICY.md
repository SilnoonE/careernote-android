# 공개 정책

## 포함

앱 소스, UI 리소스, DB 스키마, Gradle 설정·wrapper, 테스트 소스와 개발 회고.

## 제외

- 실제 광고 ID와 운영 광고 컴포넌트·초기화
- 서명 파일, 키·비밀번호, 토큰과 서비스 비밀정보
- local.properties, IDE 설정, 로컬 JDK 설정
- 사용자 DB, 첨부 PDF, 백업 ZIP, 개인 기록
- APK/AAB, release 디렉터리, 빌드 산출물·캐시

공개용 사본만 가공했으며 원본 앱은 변경하지 않았습니다.
Git ignore만으로 비밀을 보호하지 않습니다. 커밋 전 파일 목록과 내용 검사를 반복해야 합니다.
현재 공개 사본에는 GitHub 계정, 원본 컴퓨터의 절대 경로, 대화 원문을 포함하지 않습니다.
